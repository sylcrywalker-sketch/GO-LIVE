# Настоящий микрофон: 60–90 секунд после коррекции №2

**Подготовлено, ещё не проведено.** Контролируемый повтор распознанных строк не заменяет эту проверку. Viewer Core пока не принят; слияния в main нет.

1. Открыть сцену `GL`, оставить выбранные Whisper turbo и Ministral без изменений. Включить RU-распознавание, подключить Trich и начать эфир.
2. Проверять при 2–3 присутствующих зрителях. Для именованного шага нужна присутствующая Зина; отсутствие зрителя не исправлять выдуманным ответом или удалением сохранения.
3. В **GO! LIVE → Viewer Core → Reaction Monitor** включить **Record session**. При желании включить **+ mic audio** для локальной записи следующего разбора.

| Время | Реплика / действие | Что проверяем |
|---|---|---|
| 0–20 с | «Как у вас дела, что сегодня делали?» Дождаться ответов. | Обычно несколько разных ответов с паузами. Каждый говорит о своём состоянии; зрители отвечают стримеру. |
| 20–45 с | После обычной паузы ответить последнему собеседнику: «Почему?», «Жесть, устал наверное?» или «И как?» — по смыслу его реплики. | Тот же зритель продолжает именно эту мысль. Отсутствие `?` в расшифровке допустимо. Если выбираете более ранний ответ, назовите зрителя, чтобы адресат был однозначным. |
| 45–65 с | «Зина, а у тебя как день прошёл?» | Отвечает Зина. Случайный зритель не подменяет её при молчании или ограничении частоты. |
| 65–85 с | «Так, секунду». Помолчать, затем выключить запись. | Обычно тишина на эту фразу. Фоновые сообщения учитывать отдельно. |

Сохраняются обычные ограничения: шесть секунд между ответами зрителя, окно беседы 40 секунд, максимум пять ответов, присутствие и текущий визит. Не повторять попытку ради красивого результата; сохранить и молчание, и плохой ответ.

В журнале `Logs/ViewerSessions` проверить для каждой реплики: исходный текст, `conversationTarget`, выбранного зрителя, `questionPurpose`, `directAnswerFacts`, `previousViewerLine`, опубликованный текст и задержки. Для именованного вопроса ожидается `[explicit]`, для продолжения — `[active-thread]`, для общего вопроса — `group`.

Критерий качества: **это ощущается как разговор с маленькой группой людей?** Правильный адресат и зелёные автоматические тесты недостаточны, если ответы не связаны с вопросом. При отрицательном результате сохранить журнал; Viewer Core остаётся непринятым, модель без отдельного решения не заменять.
